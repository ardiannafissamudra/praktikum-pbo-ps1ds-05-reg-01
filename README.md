## Panduan Pengerjaan dan Pengumpulan
Silakan ikuti instruksi berikut untuk mengerjakan dan mengumpulkan tugas praktikum:

1. **Laporan Praktikum (`docs/`)**
   - Gunakan file `Template Laporan Praktikum PBO Sains Data.docx` yang telah disediakan di direktori utama repositori ini sebagai format dasar laporan Anda.
   - Setelah laporan selesai disusun, simpan (export) dokumen tersebut ke dalam format **PDF**.
   - Letakkan file PDF tersebut ke dalam folder `docs/` pada modul yang bersangkutan.
   - **Wajib** menggunakan format penamaan file berikut: `Modul[nomor modul]_[NIM]_[Nama lengkap].pdf` (contoh: `Modul01_103112400148_JohnDoe.pdf`).

2. **Source Code Java (`src/`)**
   - Letakkan seluruh *source code* (file berektensi `.java`) ke dalam folder `src/` pada modul yang bersangkutan.
   - **Rekomendasi penyusunan *source code* (agar memudahkan Asisten Praktikum saat mengoreksi):**
     - **Gunakan Package:** Kelompokkan file ke dalam *package* yang sesuai agar terstruktur dengan baik (contoh: `package modul01.tugas;`).
     - **Penamaan File/Class:** Gunakan penamaan *class* yang mudah diidentifikasi (contoh: `Tugas1_Kalkulator.java`).
     - **Komentar Header:** Sangat disarankan untuk menambahkan komentar singkat di baris teratas file *class* utama yang memuat Nama, NIM, dan deskripsi singkat tentang kegunaan program.
     - **Hanya Source Code:** Pastikan hanya men-submit *source code* aslinya. File hasil kompilasi program (`.class`) tidak perlu disubmit (sudah diabaikan oleh `.gitignore`).
